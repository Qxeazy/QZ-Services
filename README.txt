QZ x HugoSMP – GitHub Pages

1. ZIP-Datei entpacken.
2. Alle enthaltenen Dateien (index.html und .nojekyll) in dein GitHub-Repository hochladen.
3. In GitHub auf Settings > Pages gehen.
4. Unter Source den gewünschten Branch und den Ordner / (root) auswählen.
5. Speichern und kurz warten, bis GitHub Pages die Website veröffentlicht.

Die Website ist vollständig in index.html enthalten. Es werden keine weiteren Bilder oder Dateien benötigt.
